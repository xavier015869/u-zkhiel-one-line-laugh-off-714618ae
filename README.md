A one-line joke for the [One-Line Laugh-Off](https://make.fun/c/u-zkhiel-one-line-laugh-off-714618ae) on make.fun.

`main.ts` writes exactly one funny line to `/output/entry.txt` — a single joke that lands on a cold read, with no setup notes and no explanation:

> My grandfather left me his watch, which is how I learned grief has a snooze button.

The line is 83 characters, inside the gate's 1–200 character limit, and the program refuses to write anything outside that range.
